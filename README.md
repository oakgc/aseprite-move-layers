MOVE LAYERS

Move Layers is an Aseprite Extension that allows you to move your layers up and down using keyboard shortcuts.

The extension automatically detects the active layer and switches it based on the selected file. The Move layers give the option to move the selected layer up or down from other layers using keyboard shortcuts. 

How To Install
1. Download the file here.
2. Execute the .aseprite-extension and install that.
3. Restart the Aseprite to use this plugin.

Requirements
A sprite must be open to use this extension. If no sprite is open, you cannot access the menu to use the extension. 

How to use
Move Layers can be accessed by clicking the rightmost menu in the Layers section, which will open the Move layers menu.

Or you can use the keyboard shortcuts to execute the actions:

Ctrl + Up - Move the selected layer UP
Ctrl + Down - Move the selected layer DOWN
